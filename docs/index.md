## 🐾 关于我

我的圈名叫“**雄龙ztz**”，但我在网络上习惯使用“**小狼**”这个更亲近的称呼。为了方便交流，你可以用这个更亲近的称呼来称呼我，在人称方面，你可以叫我“他”或者“he”。

我是一个于**2002年1月11日**出生于内蒙古自治区的人，简单来说，我是一个**兴趣广泛、思维活跃、富有创造力和技术热情**的人。

我的MBTI是**INTJ**型，对于性取向方面的问题我暂且保密，有小众而广泛的爱好，在下文会展开说明。

我可能是一个表面看上去高冷，但实际上内心非常**渴望受到关注**的人。

我的精神状态**可能不是很好，不希望受到刺激**，我也不希望看到发生在身边的悲剧。

我看起来像是一个神秘的人，但这只是为了保持我的边界。我倾向于**在自己的个人群组活动**，而不是参与别人的群（除非我与群主或相关人员很熟）。同时我不喜欢刷各类展示自己信息流，例如微博，B博（B站动态），Twitter（现X），QQ空间等。

我喜欢**一切都按照计划之内运行**，否则我会觉得不知所措，以及我讨厌失去掌控感。在部分领域我会体现出J的倾向，而另一部分领域可能倾向于P。

我喜欢一些老旧的物件，比如**CD光盘，老旧的电子元件，旧电器**等等。

我是个**唯物主义者**，我喜欢使用科学和系统的方式**解构**这个世界。我认为万物皆可创造，正所谓“**自己动手，创造这个世界**”。
