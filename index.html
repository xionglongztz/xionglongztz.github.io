    🐺 小狼的实验室

    “只做自己喜欢的事” ———— 雄龙ztz

    你好，陌生人，初次见面，请多关照。

    🐾 关于我

    我的圈名叫“雄龙ztz”，但我在网络上习惯使用“小狼”这个更亲近的称呼。为了方便交流，你可以用这个更亲近的称呼来称呼我，在人称方面，你可以叫我“他”或者“he”。

    我是一个于2002年1月11日出生于内蒙古自治区的人，简单来说，我是一个兴趣广泛、思维活跃、富有创造力和技术热情的人。

    我的MBTI是INTJ型，对于性取向方面的问题我暂且保密，有小众而广泛的爱好，在下文会展开说明。

    我可能是一个表面看上去高冷，但实际上内心非常渴望受到关注的人。

    我的精神状态可能不是很好，不希望受到刺激，我也不希望看到发生在身边的悲剧。

    我看起来像是一个神秘的人，但这只是为了保持我的边界。我倾向于在自己的个人群组活动，而不是参与别人的群（除非我与群主或相关人员很熟）。同时我不喜欢刷各类展示自己的信息流，例如微博，B博（B站动态），Twitter（现X），QQ空间等。

    我喜欢一切都按照计划之内运行，否则我会觉得不知所措，以及我讨厌失去掌控感。在部分领域我会体现出J的倾向，而另一部分领域可能倾向于P。

    我喜欢一些老旧的物件，比如CD光盘，老旧的电子元件，旧电器等等。

    我是个唯物主义者，我喜欢使用科学和系统的方式解构这个世界。我认为万物皆可创造，正所谓“自己动手，创造这个世界”。

    💻 已掌握的技能

    正如我前面所述，我是一个具有技术热情的人。虽然我会的东西不是很多，但是我有在学习：

    • Visual Basic .NET ———— 这是我最擅长的领域，虽然如今已经显得过时，但它仍然是我如今最拿手的一门编程语言。你可以在GitHub上看到我开源的项目。
    • Java ———— 我于 2025 年学习，最初为了开发我的世界 (Minecraft) 服务器插件而学。你可以在Modrinth或MineBBS上看到我开发的部分服务器插件。
    • Python ———— 于本科时期计算机课设自学过，有一定的了解，但是不是很深入研究。
    • C ———— 于本科时期学习，有一定的了解，但对于更加深入的学习了解的稍微少一些。

    视频制作

    • 哔哩哔哩 ———— 我是视频网站哔哩哔哩的一位UP主，视频风格多样：涵盖游戏，音乐，鬼畜，软件开发，硬件DIY等多个领域。

    文学创作

    • Lofter ———— 如果你无法访问，你可以访问老福特查看关于我创作的内容

    其他

    • 数据分析与整理 ———— 擅长处理各类文档，文件。
    • 服务器运维 ———— 对计算机系统、网络架构有一定的了解（例如IP，端口等），了解TCP，UDP，以及相关的各种协议，可排查部分基础问题。
    • Adobe Photoshop ———— 我常常用来制作视频封面与简单的图片处理，以及部分简单的需求。

    🚫 讨厌的事物

    食物

    • 不喜欢海鲜，一方面是难扒，另一方面是有特殊的怪味，但海参我却可以接受。
    • 不喜欢芹菜，不喜欢青椒，不喜欢绝大多数动物内脏。
    • 可以接受香菜与葱花，也可以接受大蒜，但是不喜欢姜。
    • 不喜欢榴莲，但是喜欢螺蛳粉。
    • 喜欢吃辛辣的食物，并且比很多人都更能接受更辣的食物。

    行为

    • 被删好友或者被抛弃，可能是我缺乏爱导致的，但如果真的被一个关注很久的人抛弃，这种感觉真的会让我很不舒服。我本人已经被抛弃了好几次了，我不知道下一次是什么时候。
    • 被阴阳怪气，或者谜语人，或者使用任何负面色彩的言语。
    • 让我做比较艰难的选择，尤其是无法撤销的那种。
    • 被规则限制很死的情景，或者做我不喜欢的事，我讨厌这么做，我喜欢自由的感觉。除非对方是我熟悉的人或事物。
