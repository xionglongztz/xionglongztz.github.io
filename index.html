    🐾 关于我

    我的圈名叫“雄龙ztz”，但我在网络上习惯使用“小狼”这个更亲近的称呼。为了方便交流，你可以用这个更亲近的称呼来称呼我。

    我于2002年1月11日出生，简单来说，我是一个兴趣广泛、思维活跃、富有创造力和技术热情的人。

    我的MBTI是INTJ型，对于性取向方面的问题我暂且保密，有小众而广泛的爱好，在下文会展开说明。

    我可能是一个表面看上去高冷，但实际上内心非常渴望受到关注的人。

    我的精神状态可能不是很好，不希望受到刺激，我也不希望看到发生在身边的悲剧。

    💻 已掌握的技能

    正如我前面所述，我是一个具有技术热情的人。虽然我会的东西不是很多，但是我有在学习：

    编程

    • Visual Basic .NET ———— 这是我最擅长的领域，虽然如今已经显得过时，但它仍然是我如今最拿手的一门编程语言。你可以在GitHub上看到我开源的项目。
    • Java ———— 我于 2025 年学习，最初为了开发我的世界 (Minecraft) 服务器插件而学。你可以在Modrinth或MineBBS上看到我开发的部分服务器插件。
    • Python ———— 于本科时期计算机课设自学过，有一定的了解，但是不是很深入研究。
    • C ———— 于本科时期学习，有一定的了解，但对于更加深入的学习了解的稍微少一些。

    视频制作

    • Bilibili ———— 我是视频网站哔哩哔哩的一位UP主，视频风格多样：涵盖游戏，音乐，鬼畜等多个领域。
    • Vegas Pro 14 Edit ———— 我的第一款视频剪辑工具，也是我最擅长的视频剪辑工具。

    硬件

    • Verilog ———— 我对FPGA/CPLD硬件描述语言有所了解。
    • MCU ———— 我对51单片机/微控制器的开发有较为深入的了解。
    • 模拟电路 ———— 对于弱电，小部分机电领域，动力电子等领域有一定的了解，对电路具有一定的调试能力。你可以在立创开源平台上看到我开源的部分项目。
    • 数字电路 ———— 对于控制电路有一定的了解。

    文学创作

    • Pixiv ———— 我在努力创作属于我个人世界观的故事集。旨在将我的 Furry 设定变得更加完整。

    其他

    • 数据分析与整理 ———— 擅长处理各类文档，文件。
    • 服务器运维 ———— 对计算机系统、网络架构有一定的了解，可排查部分基础问题。
    • Photoshop ———— 我常常用来制作视频封面与简单的图片处理，以及部分简单的需求。

    🔭 正在学习的技能

    以下是我力求完美，正在努力学习和扩展的技术领域：

    编曲

    • FL Studio ———— 我希望能够“驾驭”这个野兽，创作属于自己的音乐风格。
    • VOCALOID ———— 我想要学习V家/术力口曲的创作（注：此处的V家专指VOCALOID而不是如今的VTuber）。
    • Adobe Audition ———— 它对于音频编辑有着重要作用。

    建模

    • Solidworks ———— 它在3D打印领域的应用非常广泛。
    • Blender ———— 很多游戏开发者都在使用它。

    绘画

    • PaintToolSAI ———— 最初的我希望创作二次元作品，如今的我希望创作Furry类型的作品（注：此处的二次元不包含任何贬义成分）。
    • Aseprite ———— 这是一个像素风格的创作工具。

    游戏开发

    • Unity3D ———— 绝大多数个人或企业开发者选择的游戏引擎。
    • Godot Engine ———— 新兴的游戏引擎。
    • RPG Maker ———— 在将来，我可能会使用它制作剧情类游戏，可能参考像是The Lar这样的作品去设计。

    现实技能

    • 游泳 ———— 一直很想去尝试但仍然没有进行实际付出。
    • 绳艺 ———— 感受独特的美感。

    其他

    • 前端三剑客(HTML + JavaScript + CSS) ———— 虽然我并不喜欢前端，我更倾向于 WinAPI，但是这可能是我为数不多妥协的时刻。
    • Kotlin ———— 进军安卓开发领域。
    • C# ———— 作为 Visual Basic .NET 的更先进的替代，并且在游戏开发上似乎也能用得到。
    • 智能体工程 ———— 尝试设计和学习更系统的项目。
    • CTF ———— 系统的学习，深入了解网络安全领域的知识点。
    • CrackMe ———— 对操作系统的深入了解，对软件的逆向，汇编，注入等知识的综合学习，学习如x64Dbg，OllyDbg，IDA等工具的使用用法。
    • Linux ———— 不局限于Windows平台，而是将自己的能力扩展到Linux。
    • VScode ———— 其余生产力工具的使用方法。
