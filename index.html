    “只做自己喜欢的事” ———— 雄龙ztz

    你好，陌生人，初次见面，请多关照。

    🐾 关于我

    我的圈名叫“雄龙ztz”，但我在网络上习惯使用“小狼”这个更亲近的称呼。为了方便交流，你可以用这个更亲近的称呼来称呼我，在人称方面，你可以叫我“他”或者“he”。

    我是一个于2002年1月11日出生于内蒙古自治区的人，简单来说，我是一个兴趣广泛、思维活跃、富有创造力和技术热情的人。

    我的MBTI是INTJ型，对于性取向方面的问题我暂且保密，有小众而广泛的爱好，在下文会展开说明。

    我可能是一个表面看上去高冷，但实际上内心非常渴望受到关注的人。

    我的精神状态可能不是很好，不希望受到刺激，我也不希望看到发生在身边的悲剧。

    我看起来像是一个神秘的人，但这只是为了保持我的边界。

    💻 已掌握的技能

    正如我前面所述，我是一个具有技术热情的人。虽然我会的东西不是很多，但是我有在学习：

    编程

    • Visual Basic .NET ———— 这是我最擅长的领域，虽然如今已经显得过时，但它仍然是我如今最拿手的一门编程语言。你可以在GitHub上看到我开源的项目。
    • Java ———— 我于 2025 年学习，最初为了开发我的世界 (Minecraft) 服务器插件而学。你可以在Modrinth或MineBBS上看到我开发的部分服务器插件。
    • Python ———— 于本科时期计算机课设自学过，有一定的了解，但是不是很深入研究。
    • C ———— 于本科时期学习，有一定的了解，但对于更加深入的学习了解的稍微少一些。

    视频制作

    • 哔哩哔哩 ———— 我是视频网站哔哩哔哩的一位UP主，视频风格多样：涵盖游戏，音乐，鬼畜，软件开发，硬件DIY等多个领域。
    • Vegas Pro 14 Edit ———— 我的第一款视频剪辑工具，也是我最擅长的视频剪辑工具。

    硬件

    • Verilog ———— 我对FPGA/CPLD硬件描述语言有所了解。
    • MCU ———— 我对51单片机/微控制器的开发有较为深入的了解。
    • 模拟电路 ———— 对于弱电，小部分机电领域，动力电子等领域有一定的了解，对电路具有一定的调试能力。你可以在我的立创开源平台上看到我开源的部分项目。
    • 数字电路 ———— 对于控制电路有一定的了解。

    文学创作

    • Pixiv ———— 我在努力创作属于我个人世界观的故事集。旨在将我的 Furry 设定变得更加完整。

    其他

    • 数据分析与整理 ———— 擅长处理各类文档，文件。
    • 服务器运维 ———— 对计算机系统、网络架构有一定的了解，可排查部分基础问题。
    • Adobe Photoshop ———— 我常常用来制作视频封面与简单的图片处理，以及部分简单的需求。

    • Linux ———— 不局限于Windows平台，而是将自己的能力扩展到Linux。

    • 汇编语言 ———— 可能会与上面的部分能力有所重合。

    • 其他单片机 ———— 我还没有学会AVR单片机及32单片机相关的知识，将在不久的将来学会。
